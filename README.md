# WedStyle 💒

WedStyle is an exclusive bridal fashion & couture Flutter application designed for Gujarati and Indian wedding wear, featuring an AI Virtual Try-On experience.

## ✨ Key Features

- **Bridal Collections:** Curated catalog across Panetar, Gharchola, Patola, Bandhani, Contemporary Bridal Lehengas, and complete wedding looks.
- **AI Virtual Try-On:** Interactive virtual try-on supporting model face selection or custom user photo uploads with identity-preserving drape logic.
- **Ceremony Curation:** Shop by wedding events including Engagement, Haldi, Mehendi, Sangeet, Wedding, and Reception.
- **Smart Sizing & Profile:** Dedicated bridal measurements and AI size recommendation profile.
- **Cart & Checkout:** Full cart management, coupon discounts, order tracking, and delivery timelines.

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (3.24+ recommended)
- Android SDK / Xcode for iOS

### Run the App
```bash
flutter pub get
flutter run
```

### Run Tests
```bash
flutter test
```
